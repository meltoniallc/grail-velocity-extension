1. Unzip grail-velocity-extension.zip
2. You should see a folder named grail-velocity
3. Open that folder. You MUST see manifest.json sitting in it (same level as background.js)
4. Chrome → chrome://extensions
5. Developer mode ON (top right)
6. Load unpacked → select the grail-velocity folder
   Do NOT select Downloads, the zip, or anything named grok-workspace
7. Pin Grail Velocity. Stay signed into eBay.
8. Any eBay tab → overlay → Scrape this page. Popup footer is the same button.
   Live search lists high-match asks. Fast-Cash still needs sold comps (Open solds).
9. Optional tape server: in this folder run `npm run tape`. It prints the secret.
   Options → paste secret → Tape API http://127.0.0.1:8787 → Check connection.
